Cold precision for every fight

Frozen Client is a lightweight Fabric mod that gives Minecraft PvP a clean ice-blue HUD, a custom crosshair, hit feedback and a drag-and-drop module menu. Free, client-side, and fair on any server.

What's inside

Sixteen modules, one clean look

Every element can be moved, scaled and recolored. Turn on only what you use.

Nine HUD modules

Real FPS, coordinates, compass, ping, CPS, keystrokes, armor durability, potion timers and a watermark.

FPSCPSKeystrokesArmorPing

HUD editor

Press H, then drag elements anywhere and pull the corner to resize. Snaps to edges and center, and can never lose an element off screen.

Custom crosshair

Cross, T, circle, square or dot. Set color, size, thickness, gap, outline and an attack cooldown bar.

Hit and damage feedback

A hit marker when your target visibly takes damage, an edge tint when you get hurt, and optional ice-shard particles.

Animations

Change how fast your arm swing looks and where first-person items sit. Purely visual; attack speed stays vanilla.

Settings that stick

Everything saves to config/frozenclient.json. A broken file is backed up and replaced with defaults instead of crashing.

Visuals only. Fair on every server.

No auto-clicking, aim help, reach changes, packet tricks or hidden-player reveals. Frozen Client only changes what you see on your own screen.

Menus

Turn them off any time

Prefer vanilla? Switch either menu, and the snowfall, off under Interface in the module menu.

Install

Ready in four steps

The download is a zip with the mod JAR and these notes inside.

  1. Install Fabric Loader for 1.21.1Use the official installer from fabricmc.net and pick Minecraft 1.21.1.
  2. Add Fabric APIDownload Fabric API for 1.21.1 from Modrinth and put it in .minecraft/mods.
  3. Add Frozen ClientUnzip the download and drop frozenclient-1.0.0.jar into the same mods folder.
  4. Launch and press Right ShiftStart the fabric-loader-1.21.1 profile. Right Shift opens the module menu.

FAQ

Questions

Will I get banned for using it?

Frozen Client only draws things on your own screen and never automates input or sends extra packets. Most servers allow HUD and visual mods like this, but every server sets its own rules, so check them if you're unsure.

Does it work on 1.21.11 or other versions?

Not yet. This release is built for 1.21.1 only, and Fabric shows a clear "requires 1.21.1" message on other versions instead of crashing.

Does it work with Sodium, Iris and other mods?

It's built on Fabric API events with a few small, documented mixins, so it is designed to sit alongside performance and shader mods.

How do I get the vanilla menus back?

Click "Vanilla menu" in the bottom-right corner of either menu, or turn off Custom Main Menu and Custom Pause Menu under Interface.

Where are my settings saved?

In .minecraft/config/frozenclient.json. Settings → Reset All Settings restores the defaults after a confirmation.
